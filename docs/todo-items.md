## C. 赛钱箱（祭坛）的祈愿配方：**现在是 0 条**

- 2026-09-24 按用户要求**删掉了唯一一条**「赛钱箱-基础祈愿」（产物 POWER存储单元 ×4）。
- 现状如实：结构 / 激活 / GUI / POWER 存储**照常**，但配方表 0 条 ⇒ 每轮 `match()==null`，
  GUI 显示「**无匹配配方（6 个预留槽需同时满足）**」，**永远不会产出**；`/touhou saizen seed` 会报"一条配方都没注册"。
- 恢复方式：在 `SaizenbakoRecipes.setup()` 里 `register(...)` 一条即可（**注册在前面的优先匹配**）。

## E. 建议的推进顺序（**待用户拍板**）

1. **A1 + A2（7 件结构件配方）** —— 收益最大：一次解锁**反应堆**与**赛钱箱**两台多方块机器，
   否则它们永远只能靠管理员发件；
2. **B（POWER 五件）** —— 让自研能源**真正可用**（现在发电机拿不到 = 网络空转）；
3. **C（祈愿配方重建）** —— 赛钱箱恢复产出（可与 B 一起定）；
4. **D 里的机制补齐**（反应堆烧原油产出炙热灰烬、落叶/回响的消耗出口）。

「反应堆框架 = 增强型工作台：强化板×8 + 铁块×1」这种粒度。**我不擅自定档位**。
